# ПетроЛаб v0.4.2

Локальная русскоязычная рабочая среда для минералогических, петрологических и геохимических данных.

Первая проверяемая версия репозитория. Основные возможности: единая SQLite-база анализов, двусторонняя синхронизация с XLSX/XLSM с резервными копиями, привязка BSE/EDS/фотографий к аналитическим точкам, минералогические пересчёты и общий конструктор диаграмм.

## Запуск Windows

1. Скачайте или клонируйте репозиторий в постоянную папку.
2. Запустите `START_PETROLAB.bat`.
3. При первом запуске автоматически создаётся `.venv` и устанавливаются зависимости.
4. Если запуск не удался, используйте `DIAGNOSE_PETROLAB.bat`.

GitHub Actions на Windows проверяет установку, расчётное ядро, Excel/SQLite-синхронизацию и запуск интерфейса Streamlit.
