# ПетроЛаб v0.14.0

Локальная русскоязычная научная рабочая среда для петрологии, минералогии и геохимии. Исходные Excel, производные минералогические расчёты, локальная интерпретация, изображения и валовые составы пород хранятся как связанные, но разные слои данных.

Интерфейс построен как спокойный светлый научный дашборд: активный проект всегда виден в боковой панели, основные рабочие разделы открываются одним кликом, а результат — таблица, график или изображение — остаётся главным объектом экрана.

## Что умеет

- Единая SQLite-база минералогических анализов из разных Excel/листов с сохранением происхождения каждой точки.
- Сравнение литературных данных по `Study/Source`: один поиск собирает минерал из нескольких статей, а целый источник можно обратимо выключить на графике без удаления или изменения QC.
- Безопасная двусторонняя синхронизация XLSX/XLSM с backup и журналом изменений.
- Per-sheet импорт: для каждого листа можно отдельно задать минерал, строку заголовков и semantic mapping; книга проходит общий preflight до сохранения.
- Нормализация названий оксидов, trace elements и единиц; bare FeO и Fe2O3 требуют явного подтверждения FeO/FeOt и Fe2O3/Fe2O3t.
- Detection-limit/censored значения сохраняются в source-слое и не превращаются молча в числовые значения структурной формулы.
- Минералогические формулы/APFU/end-members как отдельный derived-слой с provenance, immutable analysis ID и stale detection.
- Интерактивные XY и ternary диаграммы: быстрый plot-first режим, расширенный редактор, click/box/lasso, рабочие группы, изображения и ручные/MAD/IQR фильтры.
- Source-aware классификационные схемы: Morimoto pyroxene, Ab–An–Or, garnet projections, Grütter G10 diagnostics, Wyatt ilmenite reference и другие kimberlite/lamprophyre presets.
- REE и multi-element spider diagrams с CI-chondrite / primitive-mantle нормировкой только для концентраций с известной единицей.
- Гистограммы, boxplot, описательная статистика, корреляции, PCA, K-means и иерархическая кластеризация с явной обработкой слишком маленьких выборок.
- Изображения: batch-wizard, привязка фотографии к Sample, шлифу/препарату, зерну, поколению, нескольким точкам или всему набору; grid-галерея и статус потерянных связей.
- Шлифы и поля: лёгкое превью тяжёлого оригинала, препараты, поля и пространственные метки, связывающие одну позицию с отдельными EPMA/EDS/LA-ICP-MS результатами без их смешения.
- Журнальные шаблоны рисунков и таблиц (Lithos, Geodynamics & Tectonophysics, ДАН, Elsevier/Supplementary), гармоничные стили маркеров и редактируемые подписи/сетка/поля.
- Отдельная база пород: паспорт, массив/местоположение, описание, возраст и метод, валовая химия, изотопия, лаборатория/методика, фотографии и связи минерал–порода.
- Whole-rock TAS, Harker/binary, REE/spider, isotope XY и Rhodes-style olivine–rock equilibrium screening/Kd; литературные Kd также доступны как REE-D, Onuma и Kd-spider.
- Научный dashboard: task-oriented главная, toolbar-база анализов, status-first расчёты, вкладки настроек, searchable справка и отдельные «Что нового» / «История правок данных».

## Установка Windows

Для обычной работы Git и отдельный Python не нужны.

1. Откройте последний Windows Release и скачайте `PetroLab-Setup-x64.exe`.
2. Запустите установщик. Права администратора не требуются.
3. При желании оставьте включённым создание ярлыка на рабочем столе.
4. После установки запускайте PetroLab из меню «Пуск» или с рабочего стола.

Программа устанавливается отдельно от научных данных. По умолчанию база, изображения и другие пользовательские материалы PetroLab хранятся в `Документы\PetroLab Data`. Обновление и удаление программы не удаляют эту папку.

Для каждого Windows installer release публикуется файл `PetroLab-Setup-x64.sha256`, по которому можно проверить SHA-256 установщика. Установщик пока не имеет Authenticode-подписи, поэтому Windows SmartScreen на новой сборке может показать стандартное предупреждение неизвестного издателя.

## Обновление установленной версии

Закройте PetroLab и откройте в меню «Пуск» пункт **«Обновить PetroLab»**. Обновлятор скачивает конкретную проверенную ревизию, тестирует её на временной базе и только после успешной проверки переключает установленную версию. Предыдущая версия программы сохраняется как точка отката; научные данные не перезаписываются.

Пункт **«Диагностика PetroLab»** проверяет встроенный Python, зависимости, основные импорты и доступ к хранилищу.

## Разработка / Git-копия

Для разработки или ручной работы с исходным кодом по-прежнему можно клонировать репозиторий и использовать `START_PETROLAB.bat`, `UPDATE_PETROLAB.bat` и `DIAGNOSE_PETROLAB.bat`. Этот путь требует Git/Python bootstrap и не является основным способом установки для обычного пользователя.

## Основной рабочий путь

```text
Проект → Импорт
        ↓
База анализов
        ↓
Расчёты / APFU / end-members
        ↓
XY / ternary / scientific plots / statistics
        ↓
Изображения + mineral–rock links
        ↓
Таблицы / PNG / SVG / XLSX
```

### Сравнить один минерал из разных статей

1. В «Базе анализов» выберите минерал, например апатит, и одну или несколько статей в фильтре «Источник / статья».
2. Передайте текущий отбор в XY-график.
3. В блоке «Что показывать» можно временно ограничить график по источнику/статье, Sample, Generation, минералу и рабочей группе; ограничения разных категорий комбинируются.
4. Для воспроизводимого сравнения группируйте точки по колонке «Статья / источник». Интерактивная легенда подходит для быстрого preview, а plot-only visibility управляет также экспортом текущего рисунка.
5. Скрытые источники и группы остаются в базе. Фильтры видимости не меняют QC, исходную химию и научные привязки.

## Принципы безопасности

- Реальные XLSX/CSV, SQLite и изображения исключены из Git.
- Установленная программа и пользовательские научные данные физически разделены; uninstall/update не удаляют `Документы\PetroLab Data`.
- Фильтр, кластер или рабочая группа не удаляют исходный анализ.
- Derived-параметры не записываются в исходный Excel как будто они измерены.
- Неоднозначный способ представления железа не угадывается при обычном импорте.
- Censored/detection-limit значения требуют явной числовой трактовки до APFU.
- Нормированный REE/spider не принимает bare trace-element колонку без подтверждённой единицы за ppm.
- Литературные поля добавляются только вместе с источником и тестируемой геометрией; приблизительные поля «по картинке» не считаются научной классификацией.
- Whole-rock состав в mineral–rock модуле явно обозначается как proxy расплава там, где это методически важно.

GitHub Actions на Windows проверяет BAT/CRLF, архитектурные границы, импорт и синхронизацию, scientific/data-integrity regressions, минералогические формулы, classification overlays, whole-rock/statistics modules, responsive UI, реальные browser viewports и запуск PetroLab. Отдельный installer workflow собирает встроенный Python-runtime, компилирует Windows EXE, устанавливает его в чистую папку, проверяет реальный Streamlit startup, Windows PowerShell updater и сохранность пользовательских данных после uninstall.
