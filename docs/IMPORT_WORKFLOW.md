# Рабочий порядок импорта анализов

Этот документ описывает пользовательский сценарий и внутренние гарантии ПетроЛаба при импорте неоднородных Excel-файлов.

## Главное правило

ПетроЛаб не требует одинакового порядка колонок и не требует одинаковых названий служебных полей на разных листах.

Для каждого импортированного листа отдельно сохраняются:

- исходный Excel/CSV;
- имя листа;
- строка заголовков;
- исходная строка каждой аналитической точки;
- исходное имя и номер каждой колонки;
- подтверждённые семантические роли колонок;
- SHA-256 исходного файла.

Поэтому два листа могут иметь совершенно разный порядок элементов.

## 1. Выбрать проект

В разделе `Источники и импорт` выберите существующий проект или предварительно создайте новый.

## 2. Выбрать способ импорта

### Связать локальный файл

Рекомендуемый режим для постоянной научной работы. Указывается полный путь к XLSX/XLSM/CSV. ПетроЛаб сохраняет связь с этим файлом и для XLSX/XLSM может безопасно записывать подтверждённые изменения обратно с резервной копией.

### Загрузить копию

Подходит, когда постоянная связь с исходным путём не нужна. ПетроЛаб сохраняет собственную управляемую копию файла.

## 3. Указать строку заголовков

Если названия колонок находятся в первой строке, оставьте `1`. Если перед таблицей есть текст/служебные строки, укажите реальную строку заголовков.

## 4. Выбрать листы и минерал

Выберите только листы с аналитическими таблицами, которые относятся к выбранному минералогическому модулю.

Если один workbook содержит разные минералы, их безопаснее импортировать отдельными партиями: сначала листы одного минерала, затем другого. В дальнейшем интерфейс сможет поддерживать минерал отдельно для каждого листа без изменения формата базы.

## 5. Автоматическая нормализация оксидов

Порядок оксидов не учитывается вообще. ПетроЛаб идентифицирует величину по заголовку каждой колонки.

Например, следующие варианты могут быть приведены к одному внутреннему имени:

- `SiO2`, `SiO₂`, `SiO2 (wt. %)` → `SiO2`;
- `Al2O3`, `Al₂O₃` → `Al2O3`;
- `Na2O`, `Na₂O wt%` → `Na2O`;
- `FeO`, `FeOt`, `FeO total` → `FeO`.

Исходное имя при этом не теряется. Например, внутренний `SiO2` продолжает помнить, что в конкретном Excel он находился в колонке `SiO₂ (wt. %)` и был, например, пятой колонкой листа.

Неоднозначные химические величины нельзя преобразовывать молча. В частности, total Fe as Fe2O3 нельзя автоматически считать измеренным Fe2O3 с известным Fe3+/Fe2+.

Если два исходных столбца нормализуются в одно имя (например, одновременно есть `FeO` и `FeOt`), ПетроЛаб не объединяет их: второй получает технический суффикс вроде `FeO__2`, а интерфейс показывает предупреждение.

## 6. Подтвердить смысловые колонки каждого листа

Для каждого выбранного листа отдельно можно назначить канонические роли:

- `Sample` — образец;
- `Grain` — зерно;
- `Point` — аналитическая точка;
- `Generation` — генерация/группа кристаллизации.

Высокоуверенные варианты программа предлагает автоматически. Например:

- `Sample ID` → `Sample`;
- `Grain No` → `Grain`;
- `Spot` → `Point`;
- `Gen`, `Generation`, `Генерация` → `Generation`.

Неоднозначные поля (`Group`, `Type`, `Zone`, `Population`, `Series`) не становятся `Generation` автоматически. ПетроЛаб только показывает их как возможных кандидатов. Пользователь подтверждает соответствие вручную.

## 7. Проверить предпросмотр

До импорта просмотрите первые строки уже после нормализации. На этом этапе должны быть видны канонические названия оксидов и подтверждённые `Sample / Grain / Point / Generation`.

Если что-то распознано неправильно, исправьте сопоставление до импорта.

## 8. Импортировать

После подтверждения ПетроЛаб создаёт dataset для каждого выбранного листа и сохраняет его карту происхождения.

В единой базе разные листы затем объединяются по каноническим названиям независимо от исходного порядка колонок.

## 9. Привязать изображения при необходимости

После импорта откройте раздел `Изображения` и выберите dataset.

Изображение можно связать:

- со всем dataset;
- с каноническим значением поля, например `Sample = B1` или `Grain = 14`;
- с конкретным `_analysis_id`.

Для связи по полю ПетроЛаб проверяет, что выбранная колонка и значение действительно существуют. Для связи с точкой проверяется, что анализ принадлежит выбранному dataset.

## 10. Что происходит после изменения Excel вручную

ПетроЛаб сравнивает SHA-256 связанного файла с сохранённым значением. Если файл изменился, появляется статус `изменён вне ПетроЛаба`.

При обновлении dataset программа:

1. перечитывает текущий порядок колонок;
2. заново определяет их физические номера;
3. применяет сохранённую семантическую карту;
4. пересчитывает минералогические производные;
5. сохраняет `_analysis_id` прежних точек по строке источника.

Поэтому простая перестановка колонок в Excel не должна ломать базу или привязанные к точкам изображения.

## Ограничение стабильности строк

Сейчас стабильность `_analysis_id` при обновлении связанного Excel опирается на номер строки источника. Изменение значений и порядка колонок безопасно. Массовая вставка/удаление строк посередине таблицы требует более сильного алгоритма сопоставления по составному ключу (`Sample + Grain + Point`) — это отдельный запланированный слой.
